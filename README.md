# Evrakyol

Türkiye'deki resmi işlemler için, resmi kaynaklara dayalı adım adım yol haritası çıkaran web uygulaması.

Kullanıcı işlemi seçer ve birkaç seçenekli soruyu yanıtlar. Cevaplara göre gerekli evraklar, başvurulacak kurum ve adımların sırası, her adımın kaynağıyla birlikte gösterilir. Kişisel veri istenmez ve cevaplar saklanmaz.

Geliştirme aşamasındadır, henüz yayında değildir.

## Desteklenen işlemler

- Miras yoluyla araç devri
- Mirasçılık belgesi (veraset ilamı)
- Pasaport başvurusu ve yenileme
- Kimlik kartı yenileme
- Ehliyet yenileme ve değişimi
- İkametgâh / yerleşim yeri belgesi

## Teknolojiler

Next.js, TypeScript, Tailwind CSS, FastAPI, PostgreSQL (pgvector)
